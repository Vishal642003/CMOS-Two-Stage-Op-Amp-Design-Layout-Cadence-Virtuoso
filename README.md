# CMOS-Two-Stage-Op-Amp-Design-Layout-Cadence-Virtuoso
Designed a CMOS two-stage operational amplifier and implemented the corresponding custom IC layout using Cadence Virtuoso. Applied common-centroid/interdigitated transistor matching, symmetry, and structured routing for critical analog devices. Performed DRC and LVS verification, achieving 0 DRC violations  and 0 LVS mismatches.
